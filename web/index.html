Why it holds

Fees count

The budget counts everything that leaves the contract, payment plus miner fee, so many tiny payments cannot burn the balance as fees.

A clock the agent cannot rush

The window only advances by block age that the network proves (relative locktime, BIP68). Values that CSV would mask are refused.

Receipts

Every payment carries OP_RETURN "LSH1" sha256(nonce | method | url | body): which HTTP request it paid for is on chain.

Owner path

Any transaction that also spends a coin of the owner's address may move the funds: withdraw, top up, migrate. No agent key needed.

Tested like an attacker

Over 150 tests including 29 attacks with the exact rejection text, a property test of the 2× window bound, and two external reviews.

Honest limits

Fixed window (worst case 2× limit around a reset); one payment chain at a time; 0-conf settlement by default. Prototype, unaudited.
